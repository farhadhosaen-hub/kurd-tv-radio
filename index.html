دانان لەسەر شاشەی سەرەکی (Add to Home Screen)

کردنەوەی بەستەری سەرهێڵ بۆ ئەوەی دەستبەجێ ئایکۆنی ئەپەکە بچێتە سەر شاشەی سەرەکی مۆبایلەکەت.

📱 چۆنیەتی دانانی ئەپەکە لەسەر شاشەی سەرەکی:
🍎 بۆ ئایفۆن (iPhone / Safari):
١ کلیک لە دوگمەی Share (هاوبەشکردن 📤) بکە لە خوارەوەی وێبگەڕی Safari.
٢ بڕۆ خوارەوە و کلیک لە Add to Home Screen (دانان لەسەر شاشە ⊞) بکە.
٣ لە سەرەوە لای ڕاست کلیک لە Add بکە؛ دەستبەجێ دەچێتە سەر شاشە.
🤖 بۆ ئەندرۆید (Chrome / Samsung):
١ لە سەرەوە لای ڕاست کلیک لە ٣ خاڵەکە (⋮) بکە.
٢ هەڵبژاردەی 'Install app' (دامەزراندنی ئەپ 📲) یان 'Add to Home screen' دیاری بکە.
٣ کلیک لە Install بکە؛ دەستبەجێ بە فەرمی لە مۆبایلەکەتدا جێگیر دەبێت.
