# ئەپی تەلەفزیۆن و ڕادیۆی کوردی (Kurd TV & Radio)

ئەپی نایاب و پێشکەوتووی تەلەفزیۆن و ڕادیۆی کوردی.
پەخشی ڕاستەوخۆ بەرزترین کوالێتی (Full HD) و خێرایی زۆر بەرز.

## لینکی هەمیشەیی و سەرهێڵ (Permanent Live Link):
🌐 **https://farhadhosaen-hub.github.io/kurd-tv-radio/**

## تایبەتمەندییەکان:
- کەناڵە ئاسمانی و ناوخۆیییە کوردییەکان (سپێدە، پەیام، ڕووداو، چناڵ ٨، کوردستان ٢٤، گەلی کوردستان، ئاڤا، کوردسات، هتد)
- ڕادیۆ کوردی و ئاینییەکان (سپێدە FM، میحراب، سوننەت، دەنگی قورئان، نەوا، ڕووداو، هتد)
- ڕووکاری پڕ شاشە (Fullscreen) بۆ مۆبایل و کۆمپیوتەر
- گۆڕینی خێرای کەناڵەکان بەبێ وەستان
